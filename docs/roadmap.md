# Roadmap

## Post-MVP

1. **Auto-calibration** — analyze first 5s of each track to auto-set thresholds
2. **Listener reaction shots** — during long monologues (>30s), insert 3-5s of the listener's closeup
3. **Variety rule** — don't hold one camera for more than N segments in a row
4. **EDL export** — for compatibility with other NLEs
5. **GUI preview** — waveform + timeline visualization before export
6. **Video assembly** — ffmpeg concat for quick preview without NLE
